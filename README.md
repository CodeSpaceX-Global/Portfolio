# CodeSpaceX Portfolio

A responsive, animated static portfolio built with **HTML, CSS, and vanilla JavaScript**. No backend, database, build tools, or installation required.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, colors, animations, and button styles
- `script.js` — mobile navigation, reveal animations, active navigation, and back-to-top button

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

Internet is only needed to load the optional Google Fonts. The rest of the site works without a backend.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `codespacex-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` directly to the repository's root (not inside another nested folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. Wait a few minutes. GitHub Pages will show your public website URL on the Pages settings screen.

## Personalize before publishing
Search and replace these sample details in `index.html`:
- `CodeSpaceX` — brand / portfolio name
- `scriptxpay@outlook.com` — contact email (replace if needed)
- `https://github.com/codespacex-global` — GitHub profile link
- Project names, descriptions, and links — use your actual work

The second and third project cards are sample concepts. Replace them with real projects before presenting this portfolio as a list of completed work.

## Contact form
This template uses a mailto link instead of a backend form. Clicking **Say hello** opens the visitor's default email app. A real form that stores or sends messages needs a form service or backend.
